# 极简番茄钟 (Minimalist Pomodoro Timer) 🍅

这是一个基于 Chrome Manifest V3 开发的现代化番茄钟插件。默认设置为 40 分钟工作时间，旨在提醒长期伏案工作的用户定期站立活动。

## ✨ 功能特性

- **倒计时功能**：默认 40 分钟，支持自定义分钟数（1-1440分钟）。
- **实时控制**：提供开始、暂停、重置功能。
- **持久化计时**：采用 `chrome.alarms` 即使关闭浏览器插件弹窗，后台依然精准计时。
- **自定义提醒**：可以自由输入提醒内容，默认提醒：“主人，该站起来活动活动了！”。
- **系统级通知**：时间到达后，通过浏览器右上角（系统级）弹窗提醒，支持点击关闭。
- **状态存储**：自动记忆上次输入的时长和提醒内容，重置时可一键恢复默认。
- **现代 UI**：简约、干净的界面设计，适配 Chrome 原生风格。

## 📂 项目结构

```text
pomodoro-extension/
├── manifest.json    # 插件配置
├── popup.html       # 交互界面
├── popup.js         # 界面逻辑与数据绑定
├── background.js    # 后台 Service Worker (核心计时逻辑)
├── style.css        # 界面样式
└── icon.png         # 插件图标 (需自备 128x128 像素)
```

## 🚀 安装步骤

1. **下载源码**：将本项目的所有代码文件保存在一个文件夹内（例如命名为 `pomodoro-timer`）。
2. **准备图标**：在文件夹中放入一张名为 `icon.png` 的图片（推荐 128x128 像素）。
3. **打开扩展程序页面**：在 Chrome 地址栏输入 `chrome://extensions/`。
4. **启用开发者模式**：打开页面右上角的“开发者模式”开关。
5. **加载插件**：
   - 点击左上角的 **“加载已解压的扩展程序”**。
   - 选择你存放源码的文件夹。
6. **固定插件**：点击浏览器工具栏的拼图图标，将“极简番茄钟”固定在工具栏上。

## 📝 使用说明

1. **设置时间**：在分钟输入框输入你想要工作的时长。
2. **设置文字**：在“提醒内容”框输入你想在时间到后看到的文字。
3. **开始计时**：点击“开始”。此时输入框会被锁定以防误触，后台开始计时。
4. **重置状态**：点击“重置”会将提醒内容恢复为默认语，并停止当前计时。
5. **接收提醒**：时间结束后，系统会弹出通知。确保你的操作系统已允许 Chrome 浏览器发送通知。

## 🔧 技术细节 (Manifest V3)

- **Alarm API**：解决了 Service Worker 自动休眠导致的计时停止问题。
- **Storage API**：用于在 Popup 和 Background 之间同步状态，确保数据不丢失。
- **Notifications API**：调用系统级通知组件。

## ⚠️ 注意事项

- **通知权限**：如果时间到了没有弹窗，请检查：
  - Windows：设置 -> 系统 -> 通知 -> 确认 Chrome 权限已开启。
  - macOS：系统设置 -> 通知 -> 确认 Chrome 权限已开启。
- **图标要求**：必须存在 `icon.png` 文件，否则 Chrome 的通知组件可能无法正常初始化。
